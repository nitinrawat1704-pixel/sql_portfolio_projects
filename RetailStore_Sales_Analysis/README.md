# Retail Store Sales Analysis using SQL

## Project Overview

This project analyzes retail sales data using MySQL.
The objective is to generate business insights related to revenue,
customers, products, categories, payment methods, and salesperson performance.


## Database

MySQL


## Table Used

store_sales


## Database Schema

The table contains:

- sale_id
- order_date
- customer_name
- gender
- age
- city
- state
- product_name
- category
- quantity
- unit_price
- discount
- total_amount
- payment_mode
- salesperson


## SQL Concepts Used

- Database Creation
- Table Creation
- SELECT Queries
- WHERE Filtering
- ORDER BY Sorting
- Aggregate Functions
- GROUP BY Analysis
- HAVING Clause
- Subqueries
- Window Functions


## Business Analysis Performed

The project answers business questions related to:

- Total sales revenue
- Customer analysis
- Product performance
- Category revenue
- City-wise sales
- Salesperson performance
- Payment mode analysis
- Monthly sales trends


## KPI Dashboard Metrics

The project calculates:

- Total Revenue
- Total Orders
- Total Customers
- Average Order Value
- Highest Sale
- Best Selling Product
